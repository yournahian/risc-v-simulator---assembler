# RISC-V Simulator & Assembler

An interactive, RARS-inspired RISC-V simulator and assembler for Android, featuring real-time interactive debugging, syntax highlighting, register/memory inspection, and ecall console.

## Features

- **RISC-V Assembly IDE**: Code editor with syntax highlighting and file management (`.asm`, `.s`).
- **Interactive Execution**: Step through instructions, set breakpoints, reset, and run.
- **Register & Memory View**: Live view and editing of RISC-V integer registers and memory addresses.
- **Ecall Console**: Handles system calls (print integer/string, read, exit, etc.).

## Prerequisites

- [Android Studio](https://developer.android.com/studio) (Ladybug or newer recommended)
- JDK 11+
- Android SDK (API Level 36)

## Getting Started

1. Open Android Studio.
2. Select **Open** and choose this project directory.
3. Allow Gradle to sync and build the project.
4. Run the app on an Android Emulator or connected physical device.
